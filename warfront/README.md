# Боевой Фронт

PvP-игра про военную технику: самолёты, вертолёты и танки. Браузерная (HTML5 + Three.js), сенсорное управление для телефона, есть APK для Android.

## Скачать

- Android APK: https://github.com/pidor95/smoothaim/releases/download/warfront-latest/BoevoyFront.apk
- Версия для браузера (zip): https://github.com/pidor95/smoothaim/releases/download/warfront-latest/BoevoyFront-web.zip (распаковать и открыть `index.html`)

Сборку делает workflow `.github/workflows/warfront-apk.yml` при каждом пуше в `warfront/`.

## Техника

| Техника | Вооружение |
|---|---|
| Су-57 | 8 ракет с автонаводкой, пушка, флаеры, режим сверхманёвренности (вектор тяги: кобра, разворот на месте ценой скорости) |
| МиГ-29 | 8 ракет с автонаводкой, пушка, флаеры |
| AH-64 Апач | пушка 360° с разрывными снарядами, 5 ракет с автонаводкой, 10 НАР, флаеры |
| Ми-24 | пушки по бокам, 4 ракеты с автонаводкой, 10 НАР, флаеры |
| M1 Абрамс | 120-мм пушка, пулемёт, дым (в дыму танк нельзя захватить, летящие ракеты теряют цель) |

## Управление

- Палец по экрану крутит камеру. Самолёт и вертолёт летят туда, куда смотрит камера, у танка туда поворачивается башня.
- Ползунок слева задаёт скорость. ▲▼ высота вертолёта, ◀▶ поворот корпуса танка.
- Хотбар внизу выбирает оружие, кнопка ОГОНЬ стреляет (по ней тоже можно вести пальцем, чтобы крутить камеру).
- Ракеты с автонаводкой: наведите круг на цель. Прерывистый писк = идёт захват, сплошной тон = ЗАХВАТ.
- Флаеры работают, если отстрелить их, когда ракета ближе ~1.5 км. Отстрелянные раньше догорят впустую.

## Режимы

- Тренировка с ботами (NPC-самолёты, вертолёты и танки, можно отключить их стрельбу).
- Онлайн PvP по коду комнаты (WebRTC через PeerJS, нужен интернет).

## Файлы

- `index.html`: вся игра
- `lib/`: three.js r128 и PeerJS 1.5.4 (локальные копии, работает без CDN)
- `android/`: обёртка WebView для APK
