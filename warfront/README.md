# Боевой Фронт

PvP-игра про военную технику: самолёты, вертолёты и танки. Браузерная (HTML5 + Three.js), сенсорное управление для телефона, есть APK для Android.

## Скачать

- Android APK: https://github.com/pidor95/smoothaim/releases/download/warfront-latest/BoevoyFront.apk
- Версия для браузера (zip): https://github.com/pidor95/smoothaim/releases/download/warfront-latest/BoevoyFront-web.zip (распаковать и открыть `index.html`)

Сборку делает workflow `.github/workflows/warfront-apk.yml` при каждом пуше в `warfront/`.

## Техника

| Техника | Вооружение |
|---|---|
| Су-57 | 3D-модель из `models/su57.js`. 8 ракет с автонаводкой, пушка, флаеры, режим сверхманёвренности и фигуры: Кобра, Кульбит, Разворот |
| МиГ-29 | 8 ракет с автонаводкой, пушка, флаеры |
| AH-64 Апач | пушка 360° с разрывными снарядами, 5 ракет с автонаводкой, 10 НАР, флаеры |
| Ми-24 | пушки по бокам, 4 ракеты с автонаводкой, 10 НАР, флаеры |
| M1 Абрамс | 120-мм пушка, пулемёт, дым (в дыму танк нельзя захватить, летящие ракеты теряют цель) |

## Управление

- Палец по экрану крутит камеру. Самолёт и вертолёт летят туда, куда смотрит камера, у танка туда поворачивается башня.
- Ползунок слева задаёт скорость. ▲▼ высота вертолёта, ◀▶ поворот корпуса танка.
- Хотбар внизу выбирает оружие, кнопка ОГОНЬ стреляет (по ней тоже можно вести пальцем, чтобы крутить камеру).
- Ракеты с автонаводкой: наведите круг на цель. Прерывистый писк = идёт захват, сплошной тон = ЗАХВАТ.
- Флаеры без перезарядки (кнопка ФЛАЕРЫ, держать). Работают, если ракета ближе ~1.5 км.
- Ракету можно сорвать манёвром: кобра/кульбит/разворот у Су-57, полёт перпендикулярно ракете или на малой скорости (доплеровский «провал»).

## Карта и графика

Рельеф строится из фрактального шума (холмы, хребты гор по краям, река на востоке) и хранится картой высот 257×257, так что физика ходит ровно по той же поверхности, что видна на экране.
Текстура земли генерируется как спутниковый снимок: поля полосами, леса, скалы на склонах, снег на вершинах, дороги, деревни, два аэродрома.
Деревья-билборды, вода с отражением неба и бликами солнца, дымка у горизонта, тени от техники и домов, кучевые облака.
Качество графики (низкое/среднее/высокое) выбирается в меню.

## Физика

- Самолёты: подъёмная сила и сопротивление по углу атаки, тяга с падением по высоте, ограничение перегрузки 9G, инерция по крену/тангажу/рысканию, сваливание. Су-57 в режиме сверхманёвра управляет вектором тяги.
- Ракеты: разгон и полёт по инерции с сопротивлением, пропорциональное наведение, ограничение перегрузки и угла обзора головки. Захват срывается манёвром, полётом перпендикулярно ракете (доплеровский провал), флаерами и дымом.
- Вертолёты: разгон наклоном несущего винта, инерция, боковое скольжение.
- Танк: двигатель против уклона, подвеска корпуса, откат ствола, медленный поворот башни.

## Свои 3D-модели

`tools/obj2js.py` превращает OBJ в компактный JS-файл модели (нос модели должен смотреть по -X, как у экспорта из Roblox Studio):

```
python3 tools/obj2js.py su57.obj models/su57.js SU57_MODEL Object621 Object51 Object21 Object821
```

Последние аргументы: группы, которые выкидываются (шасси, кабина изнутри).

Текстурированные модели: `tools/obj2js_tex.py config.json` (OBJ + текстуры, с разделением на подвижные части: башня, ствол, винты) и `tools/gltf2js.py` (glTF, например из Blockbench).

## Режимы

- Тренировка с ботами (NPC-самолёты, вертолёты и танки, можно отключить их стрельбу).
- Онлайн PvP по коду комнаты (WebRTC через PeerJS, нужен интернет).

## Файлы

- `index.html`: вся игра
- `models/su57.js`, `models/mig29.js`, `models/apache.js`, `models/abrams.js`: 3D-модели с текстурами (Ми-24 пока собран из примитивов)
- `lib/`: three.js r128 и PeerJS 1.5.4 (локальные копии, работает без CDN)
- `android/`: обёртка WebView для APK
