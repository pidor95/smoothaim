# PHYSICS BOX

3D-песочница от первого лица для Android на движке **Godot 4.5** (рендер Mobile/Vulkan,
физика Jolt). Стиль — как в «Headshots in Hyperbox»: манекены с рэгдолл-физикой,
кровь, хедшоты.

## Что есть

* **Оружие: M1911** (модель из `assets/m1911`) — полуавтомат, 7+1 патронов,
  отдача, затвор откатывается при выстреле и встаёт на задержку на пустом магазине,
  гильзы вылетают и звенят, вспышка с подсветкой, прицеливание через мушку,
  перезарядка.
* **Локация: Дом** — гостиная, кухня, спальня, ванная, гараж, двор с забором и
  деревьями, машина, лестница на крышу. Двери на шарнирах (открываются телом
  или выстрелом), окна разбиваются на осколки, мебель и предметы — физические.
* **Манекены** бродят по дому (навигационная сетка), при выстрелах паникуют и
  убегают с поднятыми руками. Попадание в голову — мгновенный хедшот,
  в тело — урон и отшатывание. После смерти тело становится рэгдоллом
  (11 частей на суставах), по нему можно продолжать стрелять.
* **Кровь**: брызги капель с физикой, пятна на стенах/полу/мебели, раны на теле,
  кровавый след за раненым, лужа под телом.
* Замедление времени (x0.3), спавн манекенов, уборка тел, автоспавн.
* Настройки: чувствительность, FOV, количество крови, разрешение 3D, громкость,
  тени, FPS.

## Управление

Телефон: левая часть экрана — джойстик, правая — обзор свайпом. Кнопка
«ОГОНЬ» тоже крутит камеру, если вести по ней пальцем. Сверху справа —
замедление, «+» манекен, пауза. «Назад» на Android — пауза.

ПК: WASD, мышь, ЛКМ — огонь, ПКМ — прицел, R — перезарядка, Space — прыжок,
E — манекен, Q — замедление, Esc — пауза.

## Сборка APK

GitHub Actions: workflow **physicsbox-android** (запускается при изменениях в
`physicsbox/` или вручную) собирает `PhysicsBox.apk` и кладёт его в artifacts.

Локально: Godot 4.5.1 + Android export templates + Android SDK, затем

```
cd physicsbox
GODOT_ANDROID_KEYSTORE_RELEASE_PATH=$PWD/android/debug.keystore \
GODOT_ANDROID_KEYSTORE_RELEASE_USER=androiddebugkey \
GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=android \
godot --headless --export-release "Android" build/PhysicsBox.apk
```

`android/debug.keystore` — стандартный отладочный ключ (пароль `android`); он лежит
в репозитории, чтобы все сборки были подписаны одинаково и обновлялись поверх
друг друга. Для публикации в магазине нужен свой ключ.

## Структура

* `scripts/` — весь код (уровень, игрок, оружие, NPC/рэгдолл, кровь, HUD, меню).
* `assets/` — модель M1911, текстуры и звуки.
* `tools/gen_sounds.py`, `tools/gen_textures.py` — процедурная генерация звуков
  и текстур; `tools/smoke_test.gd` — автотест со скриншотами.
