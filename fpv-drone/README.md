# Долина FPV

3D-симулятор FPV-дрона для Android на движке Godot 4.3.

## Что внутри

- **Карта 3,6 × 3,6 км**: луга с травой, которая колышется на ветру, лес, озеро,
  город с улицами, разметкой и небоскрёбами, кольцо гор со снежными вершинами.
- **Трасса из 18 ворот**: луг → озеро → улицы города → горный перевал → обратно.
  Время круга и рекорд сохраняются.
- **Два режима управления**
  - *Лёгкое (стрелки)*: слева вперёд/назад/повороты, справа вверх/вниз. Высота держится сама.
  - *Казуальное (стики)*: как настоящий дрон в режиме Angle. Левый стик: газ (центр = зависание)
    и поворот. Правый стик: наклоны. Если отпустить стик, дрон выравнивается сам.
- **Настройки**: тени вкл/выкл, блум вкл/выкл, качество графики, вид FPV или сзади,
  наклон FPV-камеры, чувствительность, звук.
- OSD как в настоящем FPV: напряжение батареи 4S, высота, скорость, авиагоризонт,
  указатель на следующие ворота. При крушении на экране помехи аналогового видео.
- Работает геймпад, а на компьютере клавиатура (W/S/A/D + стрелки, C — камера, Esc — пауза).

## Как получить APK

APK собирает GitHub Actions (workflow `android-apk`) при каждом пуше в эту папку.
Готовый файл лежит в релизе **fpv-latest** на странице Releases репозитория.
Его же можно скачать как artifact `DolinaFPV-apk` из запуска workflow.

Установка: скачайте `DolinaFPV.apk` на телефон, откройте и разрешите установку
из неизвестных источников.

## Своя модель дрона

Положите модель в `models/drone.glb` (или `.gltf`, `.fbx`, `.obj`).
Подробности в `models/README.txt`.

## Редактирование

Откройте папку `fpv-drone` в Godot 4.3. Весь мир строится кодом в `scripts/world.gd`,
физика дрона в `scripts/drone.gd`, меню в `scripts/menu.gd`.

APK подписан тестовым ключом из `android-signing/`. Для публикации в магазине
нужен собственный ключ.
