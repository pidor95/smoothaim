Своя модель дрона
=================

Положите сюда файл модели с одним из имён:

  drone.glb   (рекомендуется)
  drone.gltf
  drone.fbx
  drone.obj

Игра сама найдёт файл и покажет его вместо встроенной модели.
Модель масштабируется автоматически до размера 5-дюймового дрона
(примерно 25 см по диагонали). Нос дрона должен смотреть в -Z
(стандарт Godot/glTF), верх — в +Y. Если модель повёрнута,
поправьте константу CUSTOM_MODEL_ROTATION в scripts/drone_model.gd.
